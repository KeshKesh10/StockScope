# Paper Prototype (Text Wireframe)

## Page 1: Search (Home)
- Header: brand + nav (Search, Favorites, Login/Register)
- Hero copy: purpose and strategy lens
- Ticker input + Analyze button
- Result card:
  - Growth Rate (1Y)
  - P/E Ratio
  - Growth/P-E
  - Lynch Rule (pass/fail)
  - Analyst target, 52-week range
  - Add to Favorites button
- Modal popup for invalid ticker

## Page 2: Favorites
- Industry filter input + Filter button
- Table list:
  - Ticker, Industry, Growth %, P/E, Growth/P-E
  - Remove action

## Page 3: In-Depth Stock View
- Ticker headline
- Key metrics panel
- Additional context:
  - 52-week high/low
  - analyst target
  - company description

## User Flows
1. Guest searches ticker -> sees metrics or popup error.
2. User registers/logs in -> saves favorite.
3. User opens favorites page -> filters by industry.
4. User opens in-depth route for a selected ticker.
