# Demo Screenshare Script (5-7 mins)

1. Start app and open home page.
2. Search valid ticker (e.g., IBM):
   - Explain Growth Rate from net income endpoint.
   - Explain P/E and Lynch comparison.
   - Explain Growth/P-E ratio.
3. Search invalid ticker:
   - Show popup error behavior.
4. Register/login.
5. Save ticker to favorites.
6. Open favorites page:
   - Show saved metrics and industry field.
   - Filter by industry.
7. Open in-depth page and show analyst target + 52-week data.
8. Run unit tests in terminal and show pass result.
9. Close with architecture summary and next iteration ideas.
